Privacy Policy

Luther Aloud (lutheraloud.org) is a non-commercial YouTube channel narrating public-domain works of Martin Luther. This website is a static site hosted on GitHub Pages. It sets no cookies of its own, runs no analytics, and collects no personal information.

YouTube API Services

Luther Aloud uses an internal tool built on YouTube API Services to upload the channel's own videos, thumbnails and captions and to add them to the channel's own playlists. The tool is used only by the channel owner, on the owner's own Google account and YouTube channel. It does not access, collect, store or share any other person's data. The only Google user data it handles is the owner's own authorization token, which is stored as an encrypted secret and never shared. Use of this tool is subject to the YouTube Terms of Service and the Google Privacy Policy. The owner can revoke the tool's access at any time from the Google security settings page.
